# 🍽️ Healthy Food Restaurant Website

A responsive, multi-section landing page for a modern restaurant built with HTML, CSS, and JavaScript.

🌐 **Live Demo:** [View Website](https://devjunayed.github.io/restaurent/)

---

## 📌 Features

* **Navigation Menu:** Smooth scrolling navigation linking to Home, Menu, Promo, and Order sections.
* **Popular Menu Section:** Displays top dishes along with descriptions and pricing.
* **Promotions & Offers:** Highlighted promo banners for seasonal discounts and vouchers.
* **How It Order Guide:** Clear 3-step process explaining ordering, menu selection, and delivery.
* **Testimonials:** Customer reviews and feedback section.
* **Responsive Layout:** Designed to work across different screen sizes.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styling and layout design.
* **JavaScript:** Lightweight interactive client-side logic.
